Gere QR Codes
para qualquer link.

Ferramenta para criar QR Codes personalizados. Escolha o tipo, preencha e baixe.

Como usar.

Escolha a aba do tipo de link, preencha os dados e clique em Gerar QR Code.

Livre

  1. Cole a URL completa, sempre com https://
  2. Funciona com site, formulário, catálogo, rede social — qualquer link
  3. Clique em Gerar QR Code e baixe o PNG

WhatsApp

  1. Digite o número com 55 + DDD + número (só dígitos)
  2. Escreva a mensagem que já virá pronta (opcional)
  3. Gere o QR — quem escanear abre a conversa direto

Salvar a imagem

  • Desktop: clique em Baixar PNG e o arquivo baixa direto
  • Celular: segure a imagem do QR Code → Salvar em Fotos
  • Ou use o botão Baixar PNG para abrir o menu de compartilhamento

Dicas

  • Use fundo claro e QR escuro para melhor leitura
  • Sempre teste escaneando com o celular antes de usar
  • Para impressão em tamanhos grandes, use o tamanho máximo (1000 px)
